# 口腔細胞画像から細胞形態を定量化する深層学習

### Papanicolaou分類の順序性を利用した口腔擦過細胞画像の定量スコアリング

## 研究概要

本研究では，口腔がんのスクリーニング支援を目的として，
口腔擦過細胞画像から細胞形態の程度を
連続的な定量スコアとして表現する深層学習手法を研究している。

口腔細胞診で用いられるPapanicolaou分類は，
細胞形態をClass I〜Vの5段階に区分する。

本研究では，
このClass間に存在する順序関係を深層学習に利用し，
CNNが算出するスコアの順序とClassの順序が一致するように学習することで，
細胞形態の変化を連続的な数値として表現することを目指している。

さらに，
モデルがどの画像領域を利用してスコアを算出しているかを
Class Activation Mapping（CAM）によって分析し，
背景領域への依存を低減する手法についても検討している。

---

## 研究背景

口腔がんは，
発見時の進行度によって予後が大きく変化するため，
早期発見が重要である。

確定診断には組織生検が用いられるが，
病変部の組織を採取する必要があるため身体的な負担を伴う。

そのため，
スクリーニングや経過観察では，
口腔内の病変部をブラシなどで擦って細胞を採取する
「口腔細胞診」が利用されている。

口腔がんの発癌過程では，
正常な細胞から異型性の高い細胞へと，
細胞の形態が段階的に変化していく。

口腔細胞診では，
採取した細胞を染色して顕微鏡で観察し，

- 核の大きさ
- 核の形
- 核と細胞質の比率
- クロマチンの状態

などの細胞形態を総合的に評価する。

その評価方法の一つがPapanicolaou分類である。

Papanicolaou分類では，
細胞形態をClass I〜Vの5段階に区分する。

正常な細胞から異型性の高い細胞へと
形態が段階的に変化することを反映して，

Class I < Class II < Class III < Class IV < Class V

という順序関係を持つ。

一方で，
実際の細胞形態はClassの境界で突然変化するわけではなく，
正常な状態から異型な状態へと連続的に変化する。

そのため，
5段階のClassだけでは，

- 同じClassに含まれる細胞形態の違い
- Class間に存在する細かな形態変化

を十分に表現できない。

そこで本研究では，
Papanicolaou分類を単なる5クラス分類として扱うのではなく，
細胞形態の変化を表す「順序尺度」として捉える。

Class間の順序関係を利用して，
口腔擦過細胞画像から細胞形態の程度を
連続的な定量スコアとして表現することで，
5段階の分類だけでは表現できない細かな違いを捉えることを目指している。

---

## 研究のアイデア

Papanicolaou分類には，

Class I < Class II < Class III < Class IV < Class V

という順序がある。

このようなデータをAIで扱う方法として，
一般的な「多クラス分類」や「回帰」が考えられるが，
それぞれに課題がある。

### 多クラス分類の場合

一般的な多クラス分類では，

Class I  
Class II  
Class III  
Class IV  
Class V

をそれぞれ独立したカテゴリとして扱う。

そのため，

Class IとClass IIは比較的近い  
Class IとClass Vは大きく異なる

といったClass間の順序関係を，
学習に直接利用することができない。

### 回帰の場合

一方で，

Class I → 1  
Class II → 2  
Class III → 3  
Class IV → 4  
Class V → 5

のように数値を割り当て，
回帰問題として学習する方法も考えられる。

しかし，この方法では，

Class IとClass IIの差 = 1  
Class IIIとClass IVの差 = 1

のように，
Class間の距離を同じものとして扱うことになる。

Papanicolaou分類で定義されているのは
Class間の「順序」であり，
Class間の数値的な距離が等しいとは定義されていない。

### 本研究の考え方

そこで本研究では，
Classそのものを分類したり，
特定の数値を正解として回帰したりするのではなく，

**Class間の順序関係を利用して学習する。**

例えば，

Class II < Class III < Class IV

という画像に対して，

score(Class II) < score(Class III) < score(Class IV)

となるようにモデルを学習する。

つまり，

**「Classが高い画像ほど，大きなスコアを出力する」**

という関係を学習させる。

これにより，
Papanicolaou分類が持つ順序性を利用しながら，
細胞形態の程度を連続的なスコアとして表現することを目指す。

---

## 提案手法

口腔擦過細胞画像をCNNに入力し，
画像の特徴から1つの実数値スコアを算出する。

学習時には，
Papanicolaou分類のClass順序と
CNNが算出したスコアの順序を比較する。

この順序を学習するために，
Differentiable Sorting Networks
（微分可能ソートネットワーク：DSN）を利用する。

通常のソートでは，
2つの数値を比較し，
順序が逆であれば入れ替える処理を行う。

しかし，
通常の比較・交換処理は離散的であるため，
そのままではニューラルネットワークの学習に利用できない。

そこでDSNを用いて比較処理を連続的に近似し，

**スコアを正しいClass順序に並べるために，
どの程度入れ替えが必要か**

を損失として評価する。

順序が正しければ損失は小さくなり，
順序が乱れていれば損失は大きくなる。

この損失を小さくするようにCNNを学習することで，
Classの順序と整合する定量スコアの獲得を目指す。

---

## CNNの設計・実装

画像から細胞形態の特徴を抽出するため，
PythonとPyTorchを用いてCNNを実装している。

本研究で扱う医用画像は，
一般的な画像認識で利用される大規模データセットと比較して
利用できる学習データが限られている。

そのため，
ResNetなどの大規模なモデルをそのまま利用するのではなく，
データ数に対してモデルが過度に複雑にならないよう，
比較的小規模なCNNを設計した。

特徴抽出部は主に，

- 3×3 Convolution
- Batch Normalization
- ReLU
- MaxPooling

を組み合わせた畳み込みブロックから構成している。

特徴マップのチャネル数は，

24 → 48 → 96

と段階的に増加させている。

浅い層では，
細胞境界や核周辺の濃度変化などの局所的な特徴を捉え，
層を重ねることで，
核形状や染色状態など，
より広い範囲の細胞形態に関する特徴を抽出する構成としている。

特徴抽出後は，
Global Average Pooling（GAP）を用いて
特徴マップを集約する。

大規模な全結合層を配置する代わりにGAPを利用することで，
パラメータ数を抑えながら画像全体の特徴を表現する。

最終的に，
画像1枚に対して1つの実数値スコアを出力する。

このスコアに順序損失を適用し，

Class I < Class II < Class III < Class IV < Class V

というPapanicolaou分類の順序と整合するように
CNN全体を学習する。

---

## 順序学習の実装

順序学習では，
1枚の画像を独立して評価するのではなく，
異なるClassに属する複数の画像間の関係を利用する。

例えば，

Class I  
Class II  
Class III  
Class IV  
Class V

からそれぞれ画像を選択し，
CNNによって各画像のスコアを算出する。

得られたスコアについて，

score(Class I)
<
score(Class II)
<
score(Class III)
<
score(Class IV)
<
score(Class V)

という順序が成立するかをDSNによって評価する。

画像の組合せは多数存在するため，
すべての組合せについて毎回損失を計算すると
計算量が大きくなる。

そこで，
学習ステップごとに画像の組合せをランダムにサンプリングし，
その組合せに対して順序損失を計算する処理を実装した。

これにより，
複数画像間の相対的な順序関係を利用しながら，
効率的にCNNを学習する。

---

## モデルが何を見ているかの分析

訓練データでは，
Class順序と整合するスコアを算出するように学習が進んだ。

一方で，
検証データではClassとスコアの順序が乱れるケースが確認された。

そこで，

**「モデルは何を手掛かりにスコアを算出しているのか」**

を確認するため，
Class Activation Mapping（CAM）を用いて
モデルが注目した画像領域を可視化した。

その結果，
細胞領域だけでなく，
細胞が存在しない背景領域にも活性化が確認された。

このことから，
モデルが本来利用してほしい細胞形態だけではなく，
背景に含まれる特徴も
スコア算出に利用している可能性が考えられた。

---

## 背景バイアスへの対策

本研究で学習させたいのは，
背景ではなく細胞形態の特徴である。

そこで，
背景領域への依存を低減するため，
U-Netを用いた背景除去処理を導入した。

背景を除去した画像をCNNへ入力し，
同じ順序学習を行うことで，
背景情報を利用しにくい学習環境を構築した。

その結果，

- CAMにおける背景領域への活性化が減少
- 検証データにおけるClass順序との整合性が改善

する傾向が確認された。

一方で，
背景除去は強くすればよいわけではなかった。

背景除去が弱い場合には，
背景情報が画像中に残り，
モデルが背景を利用する可能性が残る。

一方，
背景除去を強くしすぎると，
細胞形態に関する特徴まで失われる傾向が確認された。

そのため，

**細胞形態の情報を保持しながら，
背景への依存を低減すること**

が重要となる。

---

## 実験設定

データは患者単位で
訓練データと検証データに分割した。

訓練データには，
Class I〜Vからそれぞれ30枚，
計150枚の画像を用いた。

検証データには，
Class I，II，IVからそれぞれ30枚，
計90枚の画像を用いた。

患者単位で分割することで，
同一患者の画像が
訓練データと検証データの両方に含まれないようにした。

---

## 実験結果

### 背景除去前

訓練データでは，
Classが高くなるほどスコアも大きくなるように学習が進んだ。

一方，
検証データではClassとスコアの順序に乱れが確認された。

CAMによってモデルの判断根拠を確認したところ，
細胞領域だけでなく，
背景領域にも活性化が確認された。

### 背景除去後

U-Netによる背景除去を導入したところ，
CAMにおける背景領域への活性化が抑制された。

また，
検証データにおけるClassとスコアの順序についても
改善する傾向が確認された。

さらに，
背景除去の強さを変更して比較した結果，

- 弱すぎると背景の影響が残る
- 強すぎると細胞形態の特徴が失われる

という傾向が確認された。

以上から，
背景を単純に除去するだけではなく，
細胞形態の特徴を保持しながら
背景への依存を低減することが重要であると考えている。

---

## 現在の取り組み

現在は，
背景を除去するだけでなく，

**モデルに細胞形態そのものをより強く学習させる**

方法を検討している。

その一つとして，
知識蒸留（Knowledge Distillation）の導入を検討している。

知識蒸留によって
細胞形態に関する特徴の学習を促し，
背景情報への依存を抑えることで，
未知データに対する定量スコアの汎化性能向上を目指している。

## 実装・開発内容

研究ではPythonを使用し，
PyTorchを中心に，
データ処理から深層学習モデルの実装，
学習，評価，可視化まで一連の処理を構築した。

主な実装内容は以下の通り。

- PyTorchを用いたCNNの設計・実装
- Convolution，Batch Normalization，ReLU，MaxPooling，GAPを用いたネットワーク構築
- 画像から1つの定量スコアを出力するモデルの実装
- Papanicolaou分類の順序関係を学習する損失関数の実装
- Differentiable Sorting Networksを用いた順序損失の実装
- 異なるClassの画像を組み合わせるサンプリング処理の実装
- Dataset / DataLoaderを用いた画像読み込み・学習処理
- 患者単位での訓練・検証データ分割
- U-Netを用いた背景除去処理
- CAMを用いたモデルの判断根拠の可視化
- 学習損失の推移やClassごとのスコア分布の集計・可視化
- 背景除去強度などの実験条件を変更したモデルの比較
- 実験結果に基づく原因分析と改善方法の検討
