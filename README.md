# 口腔がんの診断支援に向けた細胞画像AI

### Papanicolaou分類の順序性を利用した口腔擦過細胞画像の定量スコアリング

## 研究をひとことで

口腔内から採取した細胞画像をAIで解析し，
細胞の状態を5段階の分類だけでなく，
「どの程度正常に近いか・異常に近いか」という
連続的なスコアとして表現する研究です。

---

## 研究背景

口腔がんの予後改善には早期発見が重要です。

口腔がんの検査の一つに「口腔細胞診」があります。
口腔内の病変部をブラシなどで擦り，
採取した細胞を染色して顕微鏡で観察する方法です。

口腔細胞診では，細胞の

- 核の大きさ
- 核の形
- 核と細胞質の比率
- クロマチンの状態

などを観察し，細胞の異常度を評価します。

その評価方法の一つとして，
Papanicolaou分類が用いられています。

Papanicolaou分類では，
細胞の状態をClass I〜Vの5段階で表現します。

Class I → 正常に近い
Class V → 悪性を強く示す

というように，Classには明確な順序があります。

---

## この研究で解決したい課題

Papanicolaou分類は5段階で細胞の状態を表します。

しかし，実際の細胞形態は

正常 → 軽度の異型 → 高度の異型

のように少しずつ変化していきます。

そのため，同じClassに分類された細胞であっても，
細胞形態が完全に同じとは限りません。

例えば，同じClass IIIであっても，

「Class IIに近いClass III」

と

「Class IVに近いClass III」

が存在する可能性があります。

そこで本研究では，
細胞を5段階のClassとして分類するだけでなく，

**細胞形態の程度を連続的な数値として表現する**

ことを目指しています。

この数値を，本研究では「定量スコア」と呼んでいます。

---

## 研究のアイデア

一般的な画像分類では，

Class I
Class II
Class III
Class IV
Class V

をそれぞれ独立したカテゴリとして扱います。

しかし，Papanicolaou分類には

Class I < Class II < Class III < Class IV < Class V

という順序があります。

そこで本研究では，
この「順序」をAIの学習に利用します。

例えば，

Class IIの画像 → スコア 0.35  
Class IIIの画像 → スコア 0.58  
Class IVの画像 → スコア 0.82

のように，

**Classが高くなるほどAIが出力するスコアも大きくなる**

ように学習させます。

---

## なぜ普通の回帰ではないのか

Class I〜Vを単純に

1，2，3，4，5

としてAIに予測させる方法も考えられます。

しかし，Papanicolaou分類では，

Class IとClass IIの差

と

Class IIIとClass IVの差

が，同じ大きさであるとは定義されていません。

つまり，

Class I < Class II < Class III < Class IV < Class V

という「順序」は存在しますが，
Class間の「距離」は決まっていません。

そのため本研究では，
Classの数値そのものを予測するのではなく，

**Class間の順序関係だけを利用して学習する**

方法を採用しています。

---

## 提案手法

研究の流れは大きく次のようになります。

口腔擦過細胞画像
↓
CNNによる画像特徴の抽出
↓
1つの定量スコアを算出
↓
Classの順序とスコアの順序を比較
↓
順序が正しくなるようにCNNを学習

AIには畳み込みニューラルネットワーク（CNN）を使用しています。

画像を入力すると，
CNNが細胞の特徴を抽出し，
最終的に1つの実数値を出力します。

---

## 順序を学習する方法

複数の画像から算出されたスコアについて，

Class II < Class III < Class IV

であれば，

score(Class II)
<
score(Class III)
<
score(Class IV)

となることを目指します。

しかし，通常の「並べ替え（ソート）」は
ニューラルネットワークの学習にそのまま利用できません。

そこで本研究では，

**Differentiable Sorting Networks（微分可能ソートネットワーク）**

を利用しています。

通常は離散的な「比較・交換」というソート処理を
連続的に近似することで，

「現在のスコアの並びがどの程度正しいか」

を損失として計算できるようにしています。

この損失を小さくするようにCNNを学習することで，
Classの順序と整合する定量スコアの獲得を目指します。

---

## 使用しているCNN

医用画像では，
一般的な画像認識のように大量のデータを集めることが難しいため，
大規模なモデルをそのまま使用すると
過学習が起こる可能性があります。

そこで，
データ量とタスクの特徴を考慮して
比較的小規模なCNNを設計しています。

主な構成は以下です。

- Convolution
- Batch Normalization
- ReLU
- Max Pooling
- Global Average Pooling
- Scalar Score Output

細胞の核形状や染色状態などの
局所的な特徴を段階的に抽出し，
最終的に1つの定量スコアを算出します。

---

## AIがどこを見ているのか

AIが正しいスコアを出していたとしても，

「どこを見て判断したのか」

が分からなければ，
医療画像においては十分とは言えません。

そこで，

**Class Activation Mapping（CAM）**

を使用して，
AIがスコアを算出する際に注目した画像領域を可視化しました。

その結果，
AIは細胞領域だけでなく，
細胞が存在しない背景領域にも反応していることが分かりました。

つまり，

**本来注目してほしい細胞形態だけでなく，
背景の特徴も判断材料として利用している可能性**

がありました。

---

## 背景バイアスへの対策

背景への依存を減らすため，
U-Netを用いて背景を除去する前処理を導入しました。

背景除去後の画像を用いて学習することで，
CAMにおける背景領域への反応が減少し，
細胞領域への注目が相対的に強くなることを確認しました。

また，検証データにおいても，
Classの順序とスコアの順序の整合性が
改善する傾向が確認されました。

一方で，
背景を強く除去すればよいわけではありません。

背景除去が弱い場合
→ 背景情報が残る

背景除去が強すぎる場合
→ 細胞形態の特徴まで失われる

という問題があります。

そのため，

**細胞形態を残しながら背景の影響を抑える**

適切なバランスが重要だと考えています。

---

## 現在取り組んでいること

現在は，
背景を単純に消すだけではなく，

**AIに細胞形態そのものをより強く学習させる**

方法を検討しています。

その一つとして，
知識蒸留（Knowledge Distillation）を用いた学習を検討しています。

細胞形態に関する特徴の学習を促し，
背景情報への依存を減らすことで，

未知の患者画像に対しても安定した
定量スコアを算出できるモデルを目指しています。

---

## 実験を通して分かったこと

本研究では，
単にモデルの精度を上げるだけでなく，

「なぜその結果になったのか」

を分析することを重視しています。

これまでの実験から，

1. Classの順序情報を利用することで，
   Class順序と整合するスコアを学習できる

2. 訓練データでは順序を学習できても，
   未知のデータでは順序が崩れる場合がある

3. CAMによって，
   AIが背景領域を判断材料として利用している可能性を発見した

4. 背景除去によって，
   背景への依存を低減できる可能性を確認した

5. 背景を除去しすぎると，
   必要な細胞形態まで失われる

ことが分かりました。

この結果から，
医療画像AIでは単に予測結果を見るだけでなく，

**モデルが何を根拠として判断しているかを確認すること**

が重要だと考えています。

## この研究で特に意識していること

この研究で特に意識しているのは，

**「AIの性能を上げること」自体を目的にしないこと**

です。

口腔細胞診では，
医師が細胞の形態を見て診断しています。

そのため，
AIが高い性能を出したとしても，
背景や撮影条件など，
医学的に意味のない情報を利用して判断していれば，
実際の診断支援にはつながりません。

そこで，

「モデルが何を見ているのか」

をCAMで確認し，
問題があれば原因を分析し，
前処理や学習方法を改善するという流れで
研究を進めています。

技術ありきではなく，

**実際の診断に必要な細胞形態をAIが学習できているか**

を重視しています。

---

## 今後の目標

今後は，

- 細胞形態に関する特徴学習の強化
- 背景情報への依存の低減
- 未知患者に対する汎化性能の向上

に取り組みます。

最終的には，
口腔細胞診において医師の判断を補助できる
スクリーニング支援手法につなげることを目指しています。
