# 口腔細胞診画像におけるPapanicolaou分類の順序性を用いた定量スコアリング

## 研究概要

本研究では，口腔がんのスクリーニング支援を目的として，
口腔擦過細胞画像から細胞形態の程度を連続的な定量スコアとして表現する
深層学習手法を研究しています。

口腔細胞診では，採取した細胞の核の大きさや形状，
核と細胞質の比率，クロマチンの状態などを観察し，
Papanicolaou分類によってClass I〜Vの5段階に分類します。

しかし，実際の細胞形態はClassごとに明確に分離しているわけではなく，
正常な細胞から異型細胞へと段階的に変化します。
そのため，症例を5段階のClassとして分類するだけでは，
同じClassに含まれる細胞間の違いや，
Classの境界付近に存在する細かな形態変化を十分に表現できません。

そこで本研究では，
Papanicolaou分類を単なる多クラス分類ではなく
「Class I < Class II < ... < Class V」という順序を持つ尺度として捉え，
その順序情報を利用して，細胞形態の程度を1つの連続的なスコアとして
表現することを目指しています。


## 研究の着眼点

Papanicolaou分類にはClass間の順序関係がありますが，
Class間の距離が等しいとは定義されていません。

例えば，

- Class I とClass IIの差
- Class IIIとClass IVの差

が医学的に同じ大きさであるとは限りません。

そのため，Class I〜Vを単純に1〜5という数値として扱い，
通常の回帰問題として学習すると，
本来定義されていないClass間の距離までモデルに仮定させることになります。

本研究ではClassの数値そのものを予測するのではなく，

> より高いClassの画像には，より大きなスコアを与える

という相対的な順序関係のみを教師情報として利用します。

これにより，Papanicolaou分類が持つ順序性を保ちながら，
離散的なClassよりも細かな細胞形態の違いを
連続的な定量スコアとして表現することを目指しています。


## 提案手法

### 1. CNNによる定量スコアの算出

口腔擦過細胞画像をCNNへ入力し，
各画像に対して1つの実数値スコアを出力します。

一般的な多クラス分類のように
「Class Iである確率」「Class IIである確率」を出力するのではなく，
細胞形態の程度を表す1次元のスコアを直接出力する構成としています。


### 2. Class間の順序関係を利用した順序学習

学習時には，

Class I < Class II < Class III < Class IV < Class V

というPapanicolaou分類の順序を利用します。

例えばClass IIの画像とClass IVの画像を比較した場合，

score(Class II) < score(Class IV)

となるようにCNNを学習します。

一方で，各Classを特定の数値へ一致させることは要求しません。
重要なのはスコアの絶対値ではなく，
Class間の相対的な順序が保存されていることです。


### 3. 微分可能ソートネットワークによる順序損失

画像から算出された複数のスコアが
正しいClass順序に並んでいるかを評価するため，
Differentiable Sorting Networks（DSN）を用いています。

通常のソート処理では比較や交換が離散的であるため，
そのままニューラルネットワークの損失として利用できません。

そこで，比較・交換処理を連続的に近似することで，
スコア列の「並びの乱れ」を微分可能な損失として計算します。

この損失を最小化することで，
Classの順序と整合するスコアを出力するCNNを学習します。


## モデル設計

医用画像では，大量の教師付きデータを準備することが難しく，
大規模なCNNをそのまま利用すると過学習する可能性があります。

そこで本研究では，
データセットの規模と細胞画像の特徴を考慮し，
比較的小規模なCNNを設計しています。

主な構成は以下です。

- 3×3 Convolution
- Batch Normalization
- ReLU
- Max Pooling
- Global Average Pooling
- Scalar Score Output

特徴抽出部では，
細胞境界や核形状，染色状態などの局所的な画像特徴を
段階的に抽出します。


## 判断根拠の可視化

定量スコアだけでは，
モデルがどの画像領域を利用して判断したのか分かりません。

そこでClass Activation Mapping（CAM）を用いて，
スコア算出に寄与した画像領域を可視化しています。

解析の結果，
モデルは細胞領域に注目している一方で，
本来診断とは直接関係しない背景領域にも
反応していることが確認されました。

この結果から，
モデルが細胞形態だけではなく，
染色ムラや背景の特徴などを学習している可能性があると考えました。


## 背景バイアスへの対策

未知の患者画像に対する性能を向上させるためには，
背景ではなく細胞形態そのものを学習させる必要があります。

そこで，U-Netを用いて画像から背景領域を除去し，
細胞領域を中心に学習させる手法を検討しています。

背景除去を導入することで，
CAMにおける背景領域への活性化が抑制され，
検証データにおけるClass順序との整合性にも
改善傾向が確認されました。

一方で，背景を強く除去しすぎると，
細胞形態に関する情報まで失われることも確認しています。

このことから，

- 背景除去が弱い → 背景情報への依存が残る
- 背景除去が強い → 必要な細胞形態の特徴まで失われる

というトレードオフが存在すると考えています。

現在は，
細胞形態の情報を保持しながら背景への依存を抑制する方法について
検討を進めています。


## 現在の取り組み

現在は，背景除去だけに依存するのではなく，
知識蒸留を用いて細胞形態に関する特徴の学習を促すことで，
モデルの背景情報への依存を低減する手法を検討しています。

最終的には，
患者や撮影条件が変化した未知データに対しても
安定して細胞形態の程度を表現できる定量スコアの獲得を目指しています。


## 研究を通して取り組んだこと

本研究では，モデルを学習するだけでなく，
問題設定から実験・分析まで一連の研究プロセスに取り組んでいます。

- 医学的な診断基準を踏まえた機械学習問題の設計
- 口腔擦過細胞画像の前処理
- PyTorchを用いたCNNの設計・実装
- 順序学習用損失関数の実装
- Differentiable Sorting Networksを用いた学習
- 患者単位での訓練・検証データ分割
- CAMを用いた判断根拠の可視化
- U-Netを用いた背景除去
- スコア分布や損失推移を用いた学習過程の分析
- 背景バイアスや過学習の原因分析
- 実験結果を踏まえた改善手法の検討

## 研究のポイント

本研究で特に重視しているのは，
既存のClassを単純に予測することではなく，
Papanicolaou分類が本来持っている
「順序」という構造を利用して問題を設計している点です。

また，モデルの精度だけを見るのではなく，
CAMによってモデルの判断根拠を確認し，
背景領域への依存という問題を発見した上で，
背景除去や知識蒸留による改善を検討しています。

医療画像にAIを適用する際には，
単純にモデルの性能を高めるだけではなく，
「何を根拠として判断しているのか」を確認し，
実際の診断で重要な特徴を学習できているかを検証することが
重要であると考えています。
