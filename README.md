# 口腔がんのスクリーニング支援に向けた細胞画像AI

### Papanicolaou分類の順序性を利用した口腔擦過細胞画像の定量スコアリング

## 研究背景

口腔がんは，発見時の進行度によって予後が大きく変化するため，
早期発見が重要である。

確定診断には組織生検が用いられるが，
病変部の組織を採取する必要があるため身体的な負担を伴う。
そのため，スクリーニングや経過観察では，
口腔内の病変部をブラシなどで擦って細胞を採取する
「口腔細胞診」が利用されている。

口腔細胞診では，
採取した細胞を染色して顕微鏡で観察し，

- 核の大きさ
- 核の形
- 核と細胞質の比率
- クロマチンの状態

などの細胞形態を総合的に評価する。

その評価方法の一つがPapanicolaou分類である。
Papanicolaou分類では，
細胞の状態をClass I〜Vの5段階に区分する。

Class IからClass Vに向かうにつれて，
正常な細胞から異型性の高い細胞へと変化するため，

Class I < Class II < Class III < Class IV < Class V

という明確な順序関係を持つ。

一方で，実際の細胞形態は
Classの境界で突然変化するわけではなく，
正常な状態から異型な状態へと段階的に変化する。

そのため，
5段階のClassだけでは，
同じClassに含まれる細胞形態の違いや，
Class間に存在する細かな変化を十分に表現できない。

そこで本研究では，
Papanicolaou分類を単なる5クラス分類として扱うのではなく，
細胞形態の変化を表す「順序尺度」として捉える。

Class間の順序関係を利用して，
口腔擦過細胞画像から細胞形態の程度を
連続的な定量スコアとして表現することで，
5段階の分類だけでは表現できない細かな違いを捉えることを目指している。

## 研究のアイデア

Papanicolaou分類にはClass I〜Vの順序がある一方で，
Class間の差が同じ大きさであるとは定義されていない。

例えば，

Class I → 1  
Class II → 2  
Class III → 3  
Class IV → 4  
Class V → 5

のように数値を割り当てて通常の回帰を行うと，
隣り合うClass間の差をすべて「1」として扱うことになる。

しかし，本来与えられている情報は
Class間の「距離」ではなく「順序」である。

そこで本研究では，

**Classが高い画像ほど，大きなスコアを出力する**

という関係だけをモデルに学習させる。

例えば，

Class II < Class III < Class IV

という順序を持つ画像に対して，

score(Class II) < score(Class III) < score(Class IV)

となることを目指す。

これにより，
Classそのものを予測するのではなく，
細胞形態の程度を連続的なスコアとして表現する。

---

## 提案手法

口腔擦過細胞画像をCNNに入力し，
画像の特徴から1つの実数値スコアを算出する。

学習時には，
Papanicolaou分類のClass順序と
CNNが算出したスコアの順序を比較する。

この順序を学習するために，
Differentiable Sorting Networks
（微分可能ソートネットワーク：DSN）を利用する。

通常のソートでは，
2つの数値を比較し，
順序が逆であれば入れ替える処理を行う。

しかし，
通常の比較・交換処理は離散的であるため，
そのままではニューラルネットワークの学習に利用できない。

そこでDSNを用いて比較処理を連続的に近似し，

**スコアを正しいClass順序に並べるために，
どの程度入れ替えが必要か**

を損失として評価する。

順序が正しければ損失は小さくなり，
順序が大きく乱れていれば損失は大きくなる。

この損失を小さくするようにCNNを学習することで，
Classの順序と整合する定量スコアの獲得を目指す。

---

## モデルが何を見ているかの分析

訓練データでは，
Class順序と整合するスコアを算出するように学習が進んだ。

一方で，
検証データではClassとスコアの順序が乱れるケースが確認された。

そこで，

「モデルは何を手掛かりにスコアを算出しているのか」

を確認するため，
Class Activation Mapping（CAM）を用いて
モデルが注目した画像領域を可視化した。

その結果，
細胞領域だけでなく，
細胞が存在しない背景領域にも活性化が確認された。

このことから，
モデルが細胞形態だけではなく，
背景に含まれる特徴もスコア算出に利用している可能性が考えられた。

---

## 背景バイアスへの対策

本研究で本来学習させたいのは，
背景ではなく細胞形態の特徴である。

そこで，
背景領域への依存を減らすため，
U-Netを用いて背景を除去した画像で再度学習を行った。

その結果，

- CAMにおける背景領域への活性化が減少
- 検証データにおけるClass順序との整合性が改善

する傾向が確認された。

一方で，
背景除去は強くすればよいわけではなかった。

背景除去が弱い場合には，
背景情報が残り，
モデルが背景を利用する可能性が残る。

一方，
背景除去を強くしすぎると，
細胞形態に関する特徴まで失われる傾向が確認された。

そのため，

**細胞形態の情報を残しながら，
背景の影響をどこまで減らすか**

というバランスが重要となる。

---

## 実験設定

データは患者単位で訓練データと検証データに分割した。

訓練データには，
Class I〜Vからそれぞれ30枚，
計150枚の画像を用いた。

検証データには，
Class I，II，IVからそれぞれ30枚，
計90枚の画像を用いた。

患者単位で分割することで，
同一患者の画像が訓練データと検証データの両方に含まれないようにした。

---

## 実験結果

### 背景除去前

訓練データでは，
Classが高くなるほどスコアも大きくなるように学習が進んだ。

一方，
検証データではClassとスコアの順序に乱れが確認された。

CAMを用いて判断根拠を確認したところ，
細胞領域だけでなく背景領域にも活性化が確認された。

### 背景除去後

U-Netによる背景除去を導入したところ，
背景領域への活性化が抑制された。

また，
検証データにおけるClassとスコアの順序についても
改善する傾向が確認された。

さらに背景除去の強さを変えて検証した結果，

- 弱すぎると背景の影響が残る
- 強すぎると細胞形態の特徴が失われる

という傾向が確認された。

以上から，
背景を単純に除去するだけではなく，
細胞形態の特徴を保持しながら
背景への依存を低減することが重要であると考えている。

---

## 現在の取り組み

現在は，
背景を除去するだけでなく，

**モデルに細胞形態そのものをより強く学習させる**

方法を検討している。

その一つとして，
知識蒸留（Knowledge Distillation）の導入を検討している。

知識蒸留によって細胞形態に関する特徴の学習を促し，
背景情報への依存を抑えることで，
未知データに対する定量スコアの汎化性能向上を目指している。
