# 口腔細胞画像を用いた口腔がん診断支援AIの研究

## 研究概要

医師の診断支援を目的に、口腔細胞画像から口腔がんの進行度をAIで推定する研究に取り組んでいる。

口腔がんの診断では、「口腔細胞診」と呼ばれる検査方法が用いられる。口内の病変部から細胞を採取し、医師がその細胞を観察することで病気の状態を判断する。

がんの病態が進行するにつれて、細胞の形や大きさなどにも変化が現れるため、これらの形態的特徴は診断の重要な手がかりとなる。

しかし、細胞の変化がわずかな場合には判断が難しく、医師の経験に依存する部分がある。

そこで本研究では、AIに細胞画像の特徴を学習させ、進行度を推定することで、医師の判断を支援することを目指している。

## 研究目的

本研究の目的は、口腔細胞画像から口腔がんの進行度をAIで推定し、その結果を医師の診断材料の一つとして提示することである。

AIのみで診断を行うのではなく、医師が診断を行う際の判断を支援することを目指している。

## Papanicolaou分類について

口腔細胞診では、細胞の状態を評価する方法の一つとしてPapanicolaou分類が用いられる。

Papanicolaou分類では、細胞の状態を以下の5段階で表す。

- Class I
- Class II
- Class III
- Class IV
- Class V

Classが高くなるにつれて、細胞にはより強い悪性所見が現れる。

一般的な画像分類では、それぞれのClassを独立したカテゴリとして扱うことが多い。
しかし、Papanicolaou分類にはClass IからClass Vまでの順序関係が存在する。

本研究では、この順序性に着目している。

## 研究手法

### 1. CNNを用いた細胞画像の特徴抽出

細胞画像の解析には、CNN（Convolutional Neural Network）を用いる。

CNNに口腔細胞画像を入力し、細胞の形、大きさ、核など、進行度の判断に関係する画像上の特徴を学習させる。

最終的にAIから1つの連続的なスコアを出力し、このスコアを用いて細胞の状態を表現する。


### 2. Papanicolaou分類の順序性を利用した学習

通常の5クラス分類では、Class I～Vをそれぞれ別のカテゴリとして学習するため、Class間の順序関係を直接利用することが難しい。

そこで本研究では、

**Class I < Class II < Class III < Class IV < Class V**

という順序関係をAIに学習させる。

画像から出力されるスコアについても、Classが高い画像ほど大きな値となるように学習を行う。

これにより、単に5つのClassに分類するだけではなく、細胞の状態を連続的な値として表現することを目指している。

例えば、同じClass IIIに分類される画像であっても、AIが異なるスコアを出力することで、5段階の分類だけでは表現できない細胞の状態の違いをより細かく捉えられる可能性がある。


### 3. 背景への依存という課題

研究を進める中で、AIが細胞そのものだけでなく、画像の背景や染色むらなど、診断とは直接関係のない情報まで学習してしまうことが分かった。

このような背景情報を利用して推定を行うと、学習時とは異なる画像に対して正しく推定できない可能性がある。

そのため現在は、

**AIが背景ではなく、細胞本来の形態的特徴を学習できるようにすること**

を課題として研究を進めている。


### 4. U-Netを用いた背景むらの除去

背景への依存を抑える方法の一つとして、U-Netを用いた画像処理を行っている。

細胞画像には、撮影条件や染色状態によって背景に明るさや色のむらが生じる場合がある。

そこで、U-Netを用いて画像から背景成分を推定・除去し、細胞部分を強調した画像を生成する。

背景情報を事前に抑えることで、AIが細胞の形態的特徴に注目しやすくすることを目的としている。


### 5. 基盤モデルと知識蒸留を用いた学習

さらに、細胞の特徴をより重視して学習させるため、基盤モデルを活用した知識蒸留にも取り組んでいる。

基盤モデルは、大規模な画像データを用いて事前学習されており、画像中のさまざまな特徴を捉える能力を持つ。

このモデルが持つ特徴表現を教師として利用し、自身のモデルへ知識を伝えることで、背景ではなく細胞の形態的特徴を重視した学習を促す。

これにより、未知の画像に対しても安定して推定できるモデルの構築を目指している。


## 研究の流れ

本研究全体の流れは以下の通りである。

1. 口腔細胞画像を取得
2. 必要に応じて背景むらを除去
3. CNNを用いて細胞画像の特徴を抽出
4. Papanicolaou分類の順序関係を利用して学習
5. AIから連続的なスコアを出力
6. スコアから細胞の状態・進行度を推定
7. 推定結果を医師の診断支援に活用
